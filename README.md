# Ankジミー (Ankjimi)
Mi propia app para aprender japones, disfutala es gratis.

### [RECOMIENDO LEER EL RECORRIDO POR VERSIONES](https://jimi110.github.io/ankjimi/recorrido.html)

Apartados disponibles:

1. Vocabulario ordenado por niveles, más de 2mil palabras para aprender con ejercicios y frases de ejemplo, tanto en japones como coreano.
2. Repaso de errores para que el aprendizaje sea mas eficiente.
3. Aprendizaje de Hiragana y Katakana, completo, con  modos facil y dificil.
4. Panel de Estadísticas.
5. App integrada de Anki, puede leer archivos .apkg.
